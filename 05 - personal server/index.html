Core Highlights

Secure Sandbox

Hardened path traversal protection rejects all attempts to access directories outside of your chosen shared paths.

QR Mobile Connect

Dynamic QR Code generator lets you scan a code on your desktop screen to instantly connect your phone or tablet without typing URLs.

Instant Media Seeking

Supports range streams (HTTP 206 Partial Content) so you can jump to any part of your movies or music instantly.

PWA Web App

Fully installable on iOS and Android. Run it full screen like a native app with local service-worker asset caching.

Step-by-Step Setup Guide

1

Clone or Download the Repository

Get the server codebase onto your local computer. Open your terminal and run the clone command:

git clone https://github.com/your-username/your-repo-name.git
2

Install Dependencies

Navigate to the project root directory and install npm packages. This takes about 20 seconds:

npm install
3

Run the Server Launcher

Double-click the start-server.bat script inside the root folder, or start the server via command line:

npm start
4

Configure Setup Mode

Open http://localhost:8080. On the setup screen, create your Master Password. This hashes your password securely on your computer using scrypt.

5

Share & Connect!

Log in with your password, register the folders you want to share, and scan the QR code to access your files on other devices.
